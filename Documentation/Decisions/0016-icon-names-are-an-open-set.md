# 0016 — Icon names are an open set

**Status:** Accepted (Phase 6, 2026-10-19). Amends ADR 0005.

## Context

`QeetrixIconName` was a public `enum` of the icons in the catalogue. The catalogue is a representative
37 of the upstream set, and it grows: Phase 3 added 4 icons, Phase 4 added 8 and Phase 5 added 8.

Swift's API checker (`swift package diagnose-api-breaking-changes`) reports every added enum case as a
breaking change. That is correct. An app that switches over the enum without a `default` case stops
compiling when a case is added, and the library isn't built with library evolution, so there is no
`@unknown default` to protect it. Run against Phase 4 (`10b365f`), the checker reported eight breaking
changes: the eight icons Phase 5 added.

Kept as an enum, every future icon is a source-breaking change, and the checker can't tell a real break
from routine catalogue growth.

## Decision

- `QeetrixIconName` is a `struct`, generated by `qeetrix-gen`:
  - `RawRepresentable`, `Hashable`, `CaseIterable` and `Sendable`;
  - one `public static let` per icon, with the same names as the old enum cases;
  - `init?(rawValue:)`, which accepts only names in the catalogue;
  - `allCases`, in name order;
  - `mirrorsInRightToLeft`.
- Drawings are looked up in a generated table keyed by name, shape and variant, instead of a `switch`.
- Adding an icon is now an addition.

## Consequences

- **Source compatibility.** Every use of an icon name compiles unchanged: `QeetrixIcon(.bell)`,
  `QeetrixIconName(rawValue:)`, `.rawValue`, `allCases`, and `case .bell:` patterns, which match through
  `Equatable`. The only code that stops compiling is a `switch` over icons without a `default` case, the
  code that every new icon would have broken. Add `default:` to migrate.
- **Binary compatibility** is not offered: the package is distributed as source (ADR 0001).
- **One accepted break.** The checker reports the change from enum to struct once. It is recorded in
  `Documentation/API/breaking-changes-allowlist.txt`, so the CI check passes for this decision and fails
  on any other break.
- **Option enums stay enums.** `QeetrixButtonVariant`, `QeetrixChipSize` and the others follow the web's
  variants and change rarely; adding a case to one is a breaking change, made only with a decision record
  (`Documentation/Quality/API_COMPATIBILITY.md`).
